# Logo MyStay — version approuvée

Ce kit reprend directement le logo visible sur la seconde capture de référence :
le **M arrondi et régulier**, sans redessin ni modification de sa géométrie.

## Couleurs

- M : Pink 600 — `#DB2777`
- Mot-symbole : Slate 800 — `#1E293B`
- Version inversée : blanc — `#FFFFFF`

## Fichiers principaux

- `mystay-logo-approved@4x.png` : logo horizontal HD, fond transparent
- `mystay-logo-approved-reversed@4x.png` : version pour fond sombre
- `mystay-mark-approved@4x.png` : M seul en HD, fond transparent
- `mystay-app-icon-approved.png` : icône 512 px sur fond clair
- `mystay-app-icon-approved-dark.png` : icône 512 px sur fond sombre
- `favicon-16.png`, `favicon-32.png`, `favicon-64.png`, `favicon-180.png`
- `mystay-logo-approved-preview.png` : planche de contrôle

Les PNG conservent un fond transparent et peuvent être utilisés directement
avec `next/image`.
